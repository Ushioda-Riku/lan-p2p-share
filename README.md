# AirShare — LAN P2P ファイル共有 (Win ⇔ iPhone)

Windows と iPhone（Safari）などの間で、5桁のコードや QR コードを使って高速にファイル送受信を行える単一ページの Web アプリケーションです。

## 公開 URL（GitHub Pages）

https://ushioda-riku.github.io/lan-p2p-share/

## 特徴

1. **接続が固まらないハイブリッド通信（Direct P2P + E2EE WSS フォールバック）**
   - WebRTC（PeerJS）による直接 P2P 接続を自動試行しつつ、同時にエンドツーエンド暗号化（ECDH P-256 + AES-256-GCM）された WSS シグナリング＆リレー通信を並列確立します。
   - 学校・社内 Wi-Fi（AP アイソレーション有効環境）やモバイル回線越しの環境でも待ち時間なく接続を開始でき、Direct P2P が開通した瞬間は自動で高速 P2P に切り替わります。
2. **iPhone（iOS / AirDrop）ライクな UI とライト・ダーク自動対応**
   - OS のライトモード／ダークモードに自動追従し、ワンタップでのコードコピーや共有シート呼び出しに対応。
   - 受信した写真やファイルは「共有 / 写真に保存」ボタンから iOS 共有シート経由でそのまま写真アプリ等に保存できます。
3. **大容量ファイル対応（チャンク分割＆バックプレッシャー制御）**
   - 64KB（P2P 時）／ 32KB（暗号化リレー時）単位のチャンク分割と流量制御により、iPhone Safari でも安定して転送できます。

## 使い方

1. 送信側（または受信側）のブラウザで [公開 URL](https://ushioda-riku.github.io/lan-p2p-share/) を開きます。
2. iPhone のカメラで QR コードを読み取るか、相手端末で同じ URL を開いて 5 桁のコードを入力し「接続する」を押します。
3. 接続後、ファイルを選択またはドラッグ＆ドロップすると転送が始まります。
